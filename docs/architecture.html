DATABASE LAYER (ROOM V12)

Complete 19-Entity Relational Schema & DAOs

Catalog of all 19 SQLite database tables and 17 DAOs powering offline-first resilience.

Table Name Primary Key Core Fields & Foreign Keys DAO Interface Functional Responsibility
users userId (TEXT) name, email, role, kycStatus, biometricHash, phone UserDao Multi-role authentication, RBAC, and session management
loans loanId (TEXT) borrowerId, lenderId, principal, interestRate, status, purpose LoanDao Master loan state machine (PENDING, ACTIVE, REPAID)
collateral_vault vaultId (TEXT) loanId, assetType, appraisedValue, ltvCap, custodyStatus, lockerId CollateralVaultDao Asset pledge, real-time LTV valuation, and legal lock
disbursements disbursementId loanId, trancheIndex, amount, vendorVpa, milestoneProofUri, isSigned DisbursementDao Purpose-bound milestone payouts direct to suppliers
repayments repaymentId loanId, dueDate, paidDate, principalPart, interestPart, upiTxnId RepaymentDao EMI schedule tracking, non-compounding penalty calculation
marketplace_posts postId (TEXT) borrowerId, requestedAmount, collateralSummary, tenureMonths MarketplaceDao Community social orderbook for P2P syndication
marketplace_bids bidId (TEXT) postId, lenderId, bidAmount, proposedInterestRate, status MarketplaceDao Multi-lender fractional co-funding proposals
agent_visits visitId (TEXT) agentId, borrowerId, loanId, gpsLat, gpsLng, checklistJson, photoUri AgentDao Doorstep physical audit logs with tamper-evident GPS stamps
noc_certificates certificateId loanId, borrowerId, dischargeTimestamp, digitalSignatureHash NocCertificateDao Legally binding discharge deed releasing collateral lien
audit_events eventId (INT) eventType, actorId, targetId, payloadJson, timestamp, telegramDispatched AuditEventDao Immutable chronological event ledger synced to Telegram
