GeeksforGeeks & Cockburn Formal Use Case Specifications

Exhaustive requirements specifications with preconditions, triggers, main success path, alternative flows, and exception handlers.

UC-01 Authenticate & Register Biometrics (Android StrongBox)
Actor: PlatformMember | Priority: High

Pre-Conditions & Trigger

Pre-conditions: Android device runs API 26+; hardware Keystore / StrongBox Keymaster available.

Trigger: User opens application and selects 'Biometric Fast Login'.

Main Success Path

  1. App queries BiometricManager.canAuthenticate(BIOMETRIC_STRONG).
  2. System prompts biometric sensor overlay (Fingerprint / 3D Face).
  3. Android Keystore generates asymmetric ECDSA P-256 signature token.
  4. App validates token against local EncryptedSharedPreferences and establishes session.

Alternative & Exception Flows

  • 2a. Biometric Lockout: System returns BIOMETRIC_ERROR_LOCKOUT; user falls back to 6-digit cryptographic master PIN.
  • 1a. Hardware Not Available: Enrolls software AES-GCM fallback encryption.
UC-05 Create Peer-to-Peer Micro-Loan Listing
Actor: Borrower | Priority: Critical

Pre-Conditions & Trigger

Pre-conditions: Borrower authenticated; Tier-1 KYC active; active loan count < 3.

Trigger: Borrower taps 'Create Loan Request' on Marketplace.

Main Success Path

  1. Borrower inputs principal (INR 1,000 - 500,000) and tenor (1 - 36 months).
  2. Borrower selects collateral type (Unsecured, Bullion Gold, or Vehicle).
  3. System unconditionally invokes <<include>> UC-07 (Calculate Collateral LTV).
  4. System validates debt-to-income ratio and publishes listing to auction board.

Alternative & Exception Flows

  • 3a. LTV Exceeded: If LTV > 75.0% for gold, listing is rejected until collateral is topped up.
  • 1a. Amount Out of Bounds: System rejects amounts < INR 1,000 or > INR 500,000 with validation tooltip.
UC-11 Execute Promissory Note & Affidavit (Sec 4 NI Act 1881)
Actor: Borrower & Lender | Priority: Critical

Pre-Conditions & Trigger

Pre-conditions: Loan auction 100% funded; state is ESCROW_RESERVED.

Trigger: Borrower reviews terms and taps 'Sign Promissory Agreement'.

Main Success Path

  1. LoanzoPdfEngine generates dual-party PDF with statutory repayment promise.
  2. System invokes <<include>> UC-12 (Affix Digital E-Stamp).
  3. Borrower executes biometric digital signature with hardware presence gate.
  4. Lender executes matching digital counter-signature.
  5. System generates SHA-256 fingerprint and registers record in NeSL Information Utility.

Alternative & Exception Flows

  • 2a. E-Stamping Gateway Failure: System retries via state treasury API fallback buffer.
  • 4a. Lender Signature Timeout: If lender does not sign within 24h, funds are unreserved.
UC-14 Process Monthly EMI Repayment via NPCI UPI
Actor: Borrower | Priority: High

Pre-Conditions & Trigger

Pre-conditions: Active loan in REPAYING state; NPCI UPI VPA registered.

Trigger: Due date arrives or borrower taps 'Pay EMI Now'.

Main Success Path

  1. System generates NPCI UPI intent URL with exact installment amount.
  2. Borrower authorizes payment via external UPI app (GPay/PhonePe).
  3. NPCI returns payment confirmation with UTR reference number.
  4. System splits payment: principal and interest credited to lender, platform fee retained.

Alternative & Exception Flows

  • 1a. Past Due Date > 3 Days: System invokes <<extend>> UC-15 (Apply Late Penalty Fee) capped at RBI 2%/month limit.
  • 3a. UPI Network Failure: App initiates status polling against NPCI payment switch.
UC-18 Invoke Summary Legal Recovery under Order 37 CPC
Actor: Platform Admin / Lender | Priority: High

Pre-Conditions & Trigger

Pre-conditions: Borrower overdue > 90 days (NPA status); Section 4 NI Act note executed.

Trigger: Admin taps 'Initiate Legal Default Packet'.

Main Success Path

  1. System compiles verified statutory evidence dossier: signed promissory PDF, UTR logs, audit hash.
  2. System formats legal brief under Order 37 Code of Civil Procedure (Summary Suit on Negotiable Instruments).
  3. Dossier is transmitted to legal counsel and registered with Civil Court registry.
  4. Borrower account marked as LEGAL_ENFORCEMENT and credit bureaus notified.

Alternative & Exception Flows

  • 1a. Secured Collateral Present: If gold pledged, system invokes collateral liquidation auction first before civil litigation.
