DEVELOPER QUICKSTART

Local Environment Setup & Gradle Build

Instructions to clone, configure, build, and run the Android application locally on device or emulator.

# 1. Clone the repository
git clone https://github.com/Satya0810/Loanzo.git
cd Loanzo

# 2. Build Debug APK using Gradle
./gradlew assembleDebug

# 3. Prerequisites
• Android Studio Ladybug (2024.2+) or Koala
• JDK 17 (Java Development Kit)
• Minimum SDK: 26 (Android 8.0 Oreo) | Target SDK: 34 (Android 14)
• Physical Android device with Biometric fingerprint sensor (or Biometric emulator)
